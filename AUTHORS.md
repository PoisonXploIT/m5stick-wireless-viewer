# Creditos

Este proyecto nace de la fusion de dos repositorios previos:

- `PoisonXploIT/wifi-marauder-viewer` — dashboard para logs de WiFi Marauder
  (M5StickC/ESP32). Sus regex y logica de parseo viven en
  `src/m5wireless/parser/marauder.py`.
- `PoisonXploIT/Visualizacion_extendida_M5StickPlus2` — dashboard para
  Evil-M5Project (M5Stick Plus 2) con captura serial. Su logica vive en
  `src/m5wireless/parser/evil_m5project.py`.

Los repos originales se conservan como referencia historica; este proyecto no
reescribio su historial git, asi que el blame antiguo sigue disponible alli.
