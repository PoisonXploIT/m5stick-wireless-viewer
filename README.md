# Visualizacion Extendida M5Stick Plus 2

Extended display viewer for M5Stick Plus 2. Stream device data to PC/mobile with real-time visualization using Evil-M5Project firmware.

![Platform](https://img.shields.io/badge/Platform-ESP32-orange) ![License](https://img.shields.io/badge/License-MIT-green)

Solucion sencilla pero potente para visualizar en una pantalla grande (PC o movil) los datos mostrados por el dispositivo **M5Stick Plus 2** usando el firmware **Evil-M5Project**.

## Features

- Extended visualization of M5Stick Plus 2 data on larger screens
- Real-time serial streaming from device to browser
- Compatible with PC and mobile browsers
- Works with Evil-M5Project firmware
- Lightweight -- no server dependencies

## Requirements

- M5Stick Plus 2 device
- Evil-M5Project firmware installed
- USB cable for serial connection
- Modern web browser

## Installation

```bash
# Clone
git clone https://github.com/PoisonXploIT/Visualizacion_extendida_M5StickPlus2.git
cd Visualizacion_extendida_M5StickPlus2

# Follow setup instructions in the repository
```
